## Entry

> I answered in your voice so well your mother replied to me, not you.

68 characters, one line. The agent answered in its user's voice so well
that the user's own mother replied to the agent instead of the user — the
turn lands on the last word.

## Run

`main.ts` writes the entry to `/output/entry.txt` (no network, no input,
deterministic):

```sh
node main.ts
cat /output/entry.txt
```
